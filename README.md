# POO — Programação Orientada a Objetos

Exercícios e códigos feitos em aula, em Java.

Cada pasta é um projeto do IntelliJ IDEA, com os arquivos `.java` dentro de `src/`.

## Conteúdo

| Pasta | Assunto |
|---|---|
| `aula03/` | Estruturas de controle: `switch` com `Scanner` e jogo de adivinhação com `while` e `Random` |
| `aula04_01/` | Primeira classe: `Zumbi` com atributos e métodos (`apresentar`, `andar`, `morder`) |
| `aula04_02/` | Instanciação de objetos |
| `aula04_03/` | Referências de objetos: o que acontece quando `zumbi1 = zumbi2` |
| `aula04_04/` | Em andamento |
| `Exercicio1/` | Média de lanches com `Scanner`; e cálculo de aprovado/reprovado por nota |
| `untitled/` | Primeiros testes: Hello World e classe inicial |

## Como executar

Abra a pasta do exercício no IntelliJ IDEA e clique no botão de executar.

Pelo terminal, dentro da pasta `src` do exercício:

```bash
javac Main.java
java Main
```

Troque `Main` pelo nome da classe que tem o método `main`.
